ELEGANT ISLAMIC WEDDING INVITATION

1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open index.html in your browser (Live Server extension is recommended).

EDIT WEDDING CONTENT
- Names, family names, verse and invitation text: index.html
- Venue name, full address, wedding time and Hijri date: index.html
- Google Maps URL: replace https://www.google.com/maps in index.html with your exact venue directions link.
- Countdown date/time: edit the weddingDate value at the top of script.js.
  JavaScript month values start at 0: 11 means December.

OPTIONAL MUSIC
- Add an audio file you have permission to use at assets/nasheed.mp3.
- Music starts only after the visitor presses the sound button.
- No music file is included.

NOTES
- Frontend only: HTML, CSS, JavaScript and Bootstrap 5.
- Internet is needed for Google Fonts, Bootstrap CDN and Font Awesome CDN.
- Replace the example venue/time/Hijri date before publishing.
- The displayed Quran verse translation and reference are as supplied in the project brief; verify Arabic text and translation with a trusted source before public use.
